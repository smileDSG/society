Python 虚拟环境的一点记录

2026-08-19

换机器之后重装了一遍，把坑记下来。

建环境

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -U pip

导出依赖

pip freeze > requirements.txt
pip install -r requirements.txt

踩过的坑

现象原因
装了半天，跑起来还是找不到包没激活环境，装到了全局
在 VS Code 里选不到解释器选到了系统的 python，重选 .venv 里的
requirements 里一堆本机路径本地装的包被一起 freeze 进去了，换个干净的 venv 再导
